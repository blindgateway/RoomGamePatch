ROOM - Unlock Patch (All Replays + All CGs + Story Recaps)
============================================================

WHAT THIS IS
------------
A minimal patch. You must ALREADY own the game - this only
overrides two files. It does NOT include the game itself.

WHO MADE THIS
------------
github.com/blindgateway/RoomGamePatch

WHAT IT UNLOCKS
---------------
- All 37 replay scenes (Ryoujyoku + Jyunai + extra)
- All 31 event CGs
- Story recap cards before each numbered replay scene

HOW TO INSTALL
--------------
1. Close the game completely (Room.exe).
2. Open your game's install folder - the one containing Room.exe.
3. Copy the "resources" folder from this patch into the game
   folder. Windows will ask to merge - say YES, replace files.
4. Copy Room_sf.sav into the game folder (overwrite).
5. Launch Room.exe. Done.

Files in this patch (only these two live files):
  resources\app\data\scenario\RP2.ks   <- recap cards for replays
  Room_sf.sav                          <- all unlocks baked in

NOTES
-----
- The game writes Room_sf.sav on exit. Close the game fully
  BEFORE copying the save over, or the game overwrites it.
- Your normal save slots (Room_tyrano_data.sav) are untouched.
- Revert: restore your original Room_sf.sav; delete RP2.ks
  (or re-copy it from the original game).

Enjoy!
